# San-Fransico-Salary-Analysis
This project performs Exploratory Data Analysis (EDA) on the San Francisco Salaries dataset using Python and Pandas. It focuses on data cleaning, handling missing values, and analyzing salary distributions, job titles, and pay trends across different years to gain meaningful insights.

**📌 Overview
**
This project focuses on Exploratory Data Analysis (EDA) of the San Francisco Salaries dataset using Python and Pandas. It explores employee compensation, job titles, and salary trends across different years.

**🛠️ Tools & Technologies
**
Python

Pandas

NumPy

Jupyter Notebook

**🔍 Key Insights & Analysis
**
Cleaned and preprocessed real-world salary data

Handled missing and inconsistent values

Analyzed salary distribution and summary statistics

Identified common job titles and top-paid employees

Studied average base pay trends across years

Performed role-wise and employee-specific salary analysis

**▶️ How to Run
**
Keep salaries.csv in the same directory as the notebook

Open SF Salaries.ipynb in Jupyter

Run cells in order
